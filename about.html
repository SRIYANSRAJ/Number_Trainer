Section 0x02

🔐 User Authentication & System Architecture Security & Persistence

The platform enforces secure user state isolation using Firebase Authentication combined with local session fallbacks:

  • Authentication Providers: Firebase Email/Password Auth, Google OAuth integration, and seamless Guest Mode fallback.
  • Route Protection (checkAuth): Guarantees unauthorized guests are routed through the login portal (index.html) while maintaining persistent session tokens (numSysAuth & numSysUser).
  • Data Isolation (numSysCurrentUid): Each user's stats, active streak, point history, mistake notebook, and preference settings are partitioned strictly by user UID. Logging out clears sensitive local state.
  • Cloud Firestore Sync: Automatically synchronizes points, maximum streaks, total questions solved, accuracy percentages, and recent problem history to the cloud userStats collection.

🏆 Progressive Scoring Engine & Leaderboard Logic Mathematical Formula

The platform features a Progressive Score Scaling Engine designed to keep scoring balanced as learners advance through higher point tiers.

Point Reward Formula

Reward = Math.round((5 + Difficulty + Streak + Speed) × Tier Multiplier)

Every correct submission calculates points based on base reward, difficulty level, active streak, and completion time, scaled by your current score tier.

1. Base Points

+5 points base reward for every correct answer.

2. Difficulty Bonus

Easy +0 Medium +2 Hard +4 Extreme +6

3. Streak Bonus

3–4 streak +2 5–9 streak +4 10–14 streak +6 15+ streak +8

4. Speed Bonus

≤10s +3 10–20s +2 20–30s +1 >30s +0

Section 0x06

🧮 Mathematical Calculations & Answer Normalization Engine Logic

All arithmetic operations are calculated strictly using mathematical positional base algorithms:

  • Binary (Base 2): Bitwise sum Sum = (Ai + Bi + Cin) mod 2, Carry Cout = ⌊(Ai + Bi + Cin) / 2⌋.
  • Octal (Base 8): Modulo-8 arithmetic using digits 0–7.
  • Hexadecimal (Base 16): Modulo-16 arithmetic using digits 0–9 and letters A–F representing values 10–15.
  • Answer Normalization (normalizeAnswerString): Trims extraneous leading zeros and optional plus signs (e.g., 0DA ≡ DA, 00F5 ≡ F5, +7 ≡ 7) so single-box and multi-box entries match accurately regardless of zero-padding.
